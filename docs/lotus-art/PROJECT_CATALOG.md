# Отдельный каталог проектов

На preview `800eb6c` воспроизведено замечание владельца: выбор SELVEDGE, затем «Все проекты» оставлял одновременно открытую карточку справа и высокий список поверх цветка. [Контрольный кадр до исправления](catalog-proofs/before-desktop.png) снят непосредственно с публичной страницы.

«Все проекты» теперь открывает отдельный полноэкранный каталог с настоящими снимками всех одиннадцати работ. На desktop это две колонки, на телефоне — один прокручиваемый список. Цветок, подписи и карточка скрыты на время просмотра. Закреплённая кнопка закрытия остаётся доступна при прокрутке.

Выбранный проект сохраняется. Escape или кнопка закрытия возвращают именно его и фокус на открывшую каталог кнопку. Кнопка первого экрана открывает тот же каталог и получает фокус обратно. Tab и Shift+Tab остаются внутри диалога. Повторное быстрое открытие не отменяется отложенным событием предыдущего закрытия. Ссылки ведут на прежние настоящие HTML-кейсы с выбранным языком; история браузера закрывает каталог при восстановлении маршрута.

Проверки охватывают SELVEDGE → каталог → Escape, другой проект → каталог → закрытие, первый экран → каталог, переход к PERCH и Back, RU/EN/KK, 1440/390/320 px, касания и reduced motion. Каталог также доступен при отказе модели. Во время просмотра фоновое движение остановлено. Проверка фокуса читателя кейсов теперь обращается к открытому диалогу, поскольку закрытый каталог тоже присутствует в DOM.

Геометрия, материалы, контакты, тексты кейсов и реальные адреса проектов не менялись. Платных операций нет. Резервная ветка перед исправлением: `backup/pre-project-catalog-2026-11-04` (`be78c1b`). Production остаётся на `6e18031700ae46a1689e48f23ee1ecb6149da860`.

Локально прошли lint, TypeScript, 11 тестов контента/состояния, production-сборка, проверка 40 HTML-страниц и все 20 браузерных сценариев. Прогон выполнен в установленном Chrome на Windows; мобильные проверки — эмуляция viewport и касаний, не физические устройства.

Публичный preview обновлён до `cd2ad1f502c22ea1fe1ac1cfd57b4b41c5142f02`. На публичном адресе повторно прошли три целевых сценария: оба входа в каталог, весь регрессионный маршрут в трёх языках/размерах и касания.
